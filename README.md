# MIDLINE 像素中路 Solo

浏览器单机中路对线 Demo。玩家控制蓝方亚索美术角色，与红方占位 AI 对战，先取得一血、摧毁对方防御塔或补到 100 刀即可获胜。Q/W/E 和战斗数值仍是原型规则，不是亚索正式技能。

当前为森林地图试玩版本：已接入第一张 Meowa 像素地图样稿，移动、普攻、兵线、补刀、防御塔、胜负结算、Q W E 和 AI 已接通。地形与可攻击的防御塔分层。蓝方亚索复用已有八向待机/走路，并使用用户选定的A/B攻击动画；红方英雄、小兵与塔仍是程序绘制的占位像素资源。完整八向攻击、拔刀/收刀衔接、地形碰撞与最终数值平衡仍在后续阶段。

## 启动

使用 Node.js 24 或更新的兼容版本。

```sh
npm install
npm run dev
```

浏览器打开 http://127.0.0.1:5173/，点击进入对线。

```sh
npm test
npm run build
npm run preview
```

`build` 先执行 TypeScript 检查，再输出静态站点到 `dist/`。`preview` 默认在 http://127.0.0.1:4173/ 预览生产构建。

## 操作

| 操作 | 效果 |
| --- | --- |
| 右键地面 | 移动，取消尚未完成的普攻前摇 |
| 右键敌方单位 | 追踪并普攻 |
| 左键单位 | 选择单位，查看血量 |
| Q | 向鼠标方向发射棱光箭，命中首个敌方英雄或小兵 |
| W | 向鼠标方向短冲刺，获得 0.6 秒减伤 |
| E | 在鼠标位置的施法范围内释放裂光阵，预警后造成伤害和减速 |
| S | 停止移动与攻击 |
| Esc | 暂停或继续 |
| Enter | 开始、继续或在结算后再来一局 |
| Y / 镜头按钮 | 切换跟随镜头与自由镜头 |
| 按住 Space | 临时将镜头拉回英雄，不改变自由镜头模式 |
| 方向键 | 移动镜头并进入自由镜头 |
| 中键拖动 | 拖动镜头，进入自由镜头 |
| 自由镜头贴近画布边缘 | 向对应方向移动镜头 |
| 滚轮 | 切换 1× / 1.5× 局部视角，不缩回全景 |
| 点击小地图 | 查看对应区域，进入自由镜头 |

走回己方出生点光圈内恢复生命和法力。防御塔优先攻击小兵，攻击塔下敌方英雄会吸引塔仇恨。残血敌方小兵血条旁会出现浅黄色标记，表示当前血量已低于一次普攻伤害。

按 **3**（或 Ctrl+3） 可让亚索停下吹箫，同步播放新增动画和音效，动画和音效持续循环，直到操作或受击打断；移动、攻击、施法、受击或按 S 可取消。

音效默认开启，首次点击或按键后解锁播放，可在 HUD 中关闭。切换到其他窗口时比赛自动暂停。 亚索安全赶路时会间歇播放新增的两段走路音频，持续移动约 2 秒后触发，轮换间隔 16–19 秒；接近敌人、攻击或受击会中断，播放期间 BGM 自动降低。

“背景音乐”现使用官方发布的嚎哭深渊 Early Game 完整原声，可独立开关与调音量。亚索普通 Q／EQ 交替使用用户提供的 Q-v1、Q-v2，R 使用用户 MP4 提取的音轨，源文件位于 `assets/source-materials/audio/亚索音频/`，运行版本及处理记录位于 `assets/audio/yasuo-user-v1/`。其余英雄音效使用 Riot 官网基础皮肤演示音轨截取版，来源与裁切记录见 `assets/audio/riot-original/`。补刀／结算提示与小兵普通受击仍保留通用合成提示，无独立脚步声。

战斗反馈试版：在“选项 / 练习”打开“战斗手感练习”，或访问 `/?map=howling&practice=combat`。展开“训练工具”可试普攻、Q、E、Q3、R、慢放及反馈对比。命中刀光、短暂动作顿挫、受击回弹和补刀残影均由实际事件驱动；音效需单独开启，无脚步声。Q 的刀光会按预计接触时间重排播放节奏，伤害、攻速、位移与施法收招规则保持原值。

短硬直试版：英雄普攻命中造成 50ms、普通 Q 造成 70ms 的短硬直，随后同一目标获得 350ms 普通硬直保护；重复命中照常扣血，但不能刷新或叠加硬直。小兵攻击不控制，E 不增加硬直，Q3／R 保留原控制。已提交的攻击和技能继续完成；硬直中只缓冲最后一次有效移动、攻击、技能或停止指令，恢复后重新检查并执行。训练工具可切换“受击硬直”，使用“靶攻击我”“高频受击测试”检查脱身与反击。

## 代码与文档

- `src/game/`：不依赖浏览器的比赛模拟、战斗、兵线、技能与 AI。
- `src/render/`：Phaser 场景、纯镜头坐标逻辑、地图底图、单位与效果。
- `src/ui/`：音效反馈；DOM HUD 与操作连接位于 `src/main.ts`。
- `tests/`：胜负、补刀、技能、塔仇恨、暂停、重开与 AI 测试。
- [开发流程](docs/development-workflow.md)。
- [首版比赛规则](docs/match-rules.md)。
- [像素资源规格](docs/asset-spec.md)。
- [当前验证记录](docs/validation-report.md)。
- [像素冰桥画面持续优化计划](docs/visual-improvement-roadmap.md)：已接入效果、引擎能力、后续优先级与验收标准。

地图源图仍为 511 × 327，原始 PNG 未修改；地形以整数 2 倍、最近邻采样铺入游戏世界，实际地图扩展为 1022 × 654，道路与上下空间同步加宽。角色与防御塔的显示尺寸、移动速度、攻击范围保持不变，塔位、恢复点、出生点与 AI 站位按地形比例重新定位；兵线仍沿双方恢复点之间的中路线行进。

逻辑视口为 480 × 270。默认镜头 1× 显示 480 × 270 的局部世界，滚轮拉近至 1.5× 时显示 320 × 180。相比上一版默认 1.5× 镜头，角色显示尺寸缩小约 33%，视野宽高各增加 50%；主画面仍不展示整条中路。扩容后的蓝方出生点距上下边界分别约 474 / 164 个世界单位，初始镜头不再紧贴地图边界。小地图采用示意图，尺寸与点击映射跟随实际世界。镜头受到地图边界限制，右键与技能输入均转换为世界坐标。容器足够时采用整数倍显示缩放，小于原始画布的窗口使用紧凑缩放。

兵线移速和 14 秒出兵间隔没有随地形放大，抵达中路的时间会增加，后续根据试玩反馈调整节奏。

样稿角落的圆形平台作为恢复点，防御塔放在平台前方的中路。防御塔具有独立血量、攻击、碰撞半径、选中反馈和塔仇恨，不是画在背景上的装饰。整张环境底图暂未拆成遮挡层或寻路网格，河道与岩壁暂没有精细地形碰撞。

`.env` 中的 Meowa API 密钥只供本地资源制作工具使用。游戏不需要调用生成 API，也不需要后端。

## 已选定的亚索攻击循环

使用用户提供的A（高位→低位）、B（低位→高位）透明WebP，原文件逐字节存档于 `assets/heroes/yasuo/selected-2026-10-10/`。每段200×128、24帧、3秒；派生PNG图集逐帧保留RGBA像素，不剪帧、不重绘、不修改自带刀光。导入脚本 `scripts/import-yasuo-user-attacks.py` 只做本地校验和转换，不调用生成服务。

[原速A/B循环与48帧预览](http://127.0.0.1:5173/assets/hero-attacks/2026-10-10/yasuo/v14-user-selected/index.html)已包含在生产构建中。原速循环6秒；对局内保持原有0.19秒前摇和0.8秒释放后冷却，将两段各自的挥砍/收势时段映射到这两个逻辑阶段。A使用第7帧、B使用第11帧作为攻击释放姿态。伤害、射程、追踪弹和胜负规则不变，并未改造成正式亚索近战技能。

蓝方亚索已接入已有八向待机和走路。攻击只用用户提供的右下方向，不旋转或镜像伪造其他方向；走路→拔刀和收刀→走路目前仍是直接切换。每次实际释放普攻后A/B才轮换，取消未完成的前摇不推进轮换；动画跟随比赛时间，暂停冻结，重开复位。

## 亚索 16 帧走路与待机

亚索八个方向的走路、待机各有 16 帧，共 16 段、256 帧。加速走路保留 0.8 秒循环，普通走路放缓为 1.28 秒；受减速影响时步频随之降低，切换状态不重置脚步相位。待机仍为 0.8 秒。原有移动速度、角色尺寸和攻击动画不变。原版 8 帧素材保留。

[新旧同步对比与逐帧预览](http://127.0.0.1:5173/assets/hero-studies/2026-10-15/yasuo-locomotion16/index.html)支持暂停、逐帧、慢放及整数倍放大。运行图集位于 `assets/heroes/yasuo/locomotion16-2026-10-15/runtime/`，每张 512×512，包含 4×4 个 128×128 的透明帧。

## 后续迭代

三位英雄的八向待机与走路样稿已生成，共48条、384帧，其中亚索的16条已接入蓝方，其余尚未替换对局的占位角色。运行 `npm run dev` 后可打开 [完整八向动画预览](http://127.0.0.1:5173/assets/hero-animations/2026-10-09/v2/index.html)，切换英雄与方向、逐帧播放并下载透明WebP/GIF/PNG图集。预览按用户要求保留现有造型；完整资源依赖v1中复用的6条SE动画和v2新增的42条。

新增 [亚索普攻动作样稿](http://127.0.0.1:5173/assets/hero-attacks/2026-10-09/yasuo/v1/index.html)：参考英雄联盟官方亚索页R演示后半段的近身普攻，先做右下SE的一次挥刀，8帧、176×176透明画布。可单次播放、慢放、逐帧和下载；尚未定稿或接入对局。

新增 [亚索三组 A/B 普攻衔接对比](http://127.0.0.1:5173/assets/hero-attacks/2026-10-09/yasuo/v2-ab/index.html)：斜劈/反撩、横斩/回斩、短劈/挑刀，共6条、48帧，右下SE朝向。使用共享抬刀与低位关键姿势控制 A→B→A，支持同步循环、单次A+B、慢放、接缝逐帧检查和透明WebP/GIF/PNG下载。接缝仍有颜色与轮廓变化，不声明严格无缝或已接入对局。

新增 [亚索左右横挥重新生成样稿](http://127.0.0.1:5173/assets/hero-attacks/2026-10-09/yasuo/v3-horizontal/index.html)：整条动作一次生成，16帧、256×192、1.6秒，提供慢放、单次循环、首尾逐帧对比和透明WebP/GIF/PNG下载。已有横向刀路及腰肩转动，但大刀光、服装细节和首尾姿势跳变仍不合格，未宣称流畅自然定稿或接入对局。本轮消耗90积分，包含未采用的39帧初次尝试；旧版保留。

新增 [亚索独立斜向双普攻](http://127.0.0.1:5173/assets/hero-attacks/2026-10-09/yasuo/v4-diagonal-ab/index.html)：A为画面右下→左上斜撩，B为左上→右下斜砍，蓝围巾和护肩重新从原角色制作。A、B可分别单次播放，或交替检查接缝；默认仅在预览中统一每刀1.2秒，也可查看原文件时长。A12帧、B73帧，192×192；A过渡仍偏跳、B有额外红色刀光，未宣称自然流畅定稿。消耗195积分，含未采用的首尾帧A尝试；未接入对局。

先试玩检查攻击前摇、补刀节奏、塔仇恨和 AI 压力，再调数值。玩法通过验收后，依据资源规格表确认正式风格样稿并制作英雄动画、地图与音效。

技术参考：[Phaser 场景与游戏配置](https://docs.phaser.io/phaser/concepts/game)、[Phaser 输入](https://docs.phaser.io/phaser/concepts/input)、[Vite 开发与构建](https://vite.dev/guide/)。

快捷键兼容：部分浏览器或应用会在页面收到按键之前用 Ctrl+3 切换标签页，此时页面无法阻止。游戏支持单按 3（含小键盘 3）和“选项 / 练习”中的“吹箫 · 3”按钮作为可用入口；转发到页面的 Ctrl+3 会在捕获阶段处理。暂停或未开局时会显示提示。

地图提示默认收敛：我方防御塔不显示范围圈，满血时隐藏塔顶血条；敌方塔的范围边界与血条仅在玩家靠近攻击范围前约 85 世界单位时渐显，远离后消失。取消范围填色。建筑本身持续可见，规则不随镜头位置改变。普通对局隐藏 FPS 和动画帧数调试信息，战斗练习仍保留。

精简像素 HUD 已按实机参考接入：新头像、被动与技能图标位于 `assets/ui/pixel-hud-v2-2026-10-15/`。主界面不含等级、装备、金币或升级提示；QWER 保留真实冷却，D/F 因无对应机制显示为不可用。原操作与属性信息收进选项菜单。

最新 HUD 调整：小地图已移除；右上角依次显示双方英雄击杀、个人 K/D/A、补刀和时间；普通、敌我目标与技能瞄准使用原版游戏光标。我方可交战防御塔满血也显示血条，敌方仍接近才显示。

亚索 Q/W/E/R 技能声现使用本机客户端基础皮肤 SFX 包提取版（`assets/audio/yasuo-client-v1/`），与用户提供的人物语音分层；Q/E/R 接触时播放原版命中声，W 持续风声严格跟随实际风墙生命周期。旧合成技能接触音已让位给原版采样。可打开该目录 index.html 逐项试听。
