# 分析

> 仅记录值得跨轮保留的重要问题；普通讨论、临时灵感和完整对话不写入。策划提案不等于用户确认。

## 概念与范围判断

状态：user_confirmed

### 广度分析

用户明确选择“对线博弈优先”、TypeScript 和浏览器分享；因此技术方案必须优先减少部署摩擦，而不是追求完整引擎能力。

### 深度分析

对线感的最小来源不是完整 MOBA 内容，而是补刀压力、技能威胁、兵线位置和短暂推塔窗口。装备、等级和多路线会显著扩大实现面，却不直接服务本 Demo 的首要展示目标。

### 综合判断

使用原创角色、技能、命名和地图，仅借鉴中路对线的节奏与操作关系。推荐 Phaser 3 + TypeScript；固定路点替代通用寻路，程序化反馈替代高资产量特效。
