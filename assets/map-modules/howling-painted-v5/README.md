# 栏墙与神龛细节修复 v5

对应用户四张近景截图：残墙底部露蓝、火盆旁的墙脚衔接、直墙密集竖条，以及双神龛底座接地。

## 修复

- 直墙原先循环裁取兽像附墙，边缘会截到尖柱和不完整的侧面。改用本目录的专用 `parapet-run.png`，普通段与收尾段均在两柱之间的砖面裁 UV，保留完整尖柱，避免重复的薄竖条。
- 普通栏墙底线直接跟随真实桥轴和基地扩宽曲线，不再使用附墙图的近似地面斜率。
- 按源图 alpha 的实际底缘重新测量残墙和神龛脚线。最低实体表面从地面下方调整为地面上方，恢复被桥面深度测试切掉的底座、碎石和雪脚。
- 增加有厚度的墙下石沿。普通墙下只留窄沿，较深的残墙/神龛底座处局部加宽，避免底座与路面之间透出深渊。纹理在相邻石沿段之间连续，两个批次合并，避免新增大量绘制调用。

## 新资源

`parapet-run.png`：1919×820 RGBA，alpha 范围 0–255，约 76.26% 完全透明。源文件来自内置 image_gen，逐字节保存，未做离线裁图或编辑。采用已认可的 `04-central-bridge.png` 为风格参考。

一次内置生成，没有购买额度或调用外部付费生成 API。[精确提示词](parapet-run.prompt.txt)、[来源与哈希](manifest.json)。运行时通常选取 x=600–1470 的两段完整墙湾；收尾短段自动选择不会截断尖柱的砖面区间。完整源图保留。
