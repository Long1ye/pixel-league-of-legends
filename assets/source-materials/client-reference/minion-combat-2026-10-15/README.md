## 已确认的资源结构

- 蓝红双方近战、远程小兵都有独立的 Idle、Run、Attack、Death 动作引用；部分状态是别名，不能按条目数当作独立动作数量。
- 近战基础攻击配置包含独立的总时长和出手时长字段；远程也分别配置，说明动作应区分准备、发射/接触、收势。
- 近战动画图有 Attack1/2/3 等引用，不能把行走循环当作攻击替代。
- 原版的寻路碰撞半径、玩法碰撞半径、选取半径分别配置，不应按武器或特效的图像边界决定挤占位置。

这些数据仅用于动作结构参考；未解析服务端 AI 脚本或还原原版模型动画，因此下面的接敌逻辑是当前项目的适配实现，不声称逐行复刻官方 AI。保留现有像素图、攻击数值、出手时长和射程。

## 当前实现

1. 编队仅约束行军，已有敌人时允许离开精确站位接敌；进入射程便停下攻击，不再为回到编队点反复走停。
2. 保留仍有效且同优先级的目标，减少最近距离变化造成的频繁换目标；目标死亡后重新抬手，不继承旧目标的残余前摇。
3. 已接敌前排不会阻止编队参考点前进，后排仍可进入射程，防止阵形系统卡住远程单位。
4. 行走帧按实际地面位移推进，停止后不再原地踏步；每个单位有步态相位差。高刷新率下重复渲染同一模拟时刻保持相同姿态。
5. 朝向根据目标或移动方向翻转，保留脚底锚点，接近垂直方向时有翻转死区；静止有轻微呼吸起伏。
6. 远程攻击的可见弹道从武器高度衔接到目标身体，判定与伤害时刻不变。
7. 小兵死亡保留短暂倒地、压低和淡出表现，兵线互杀也生效；这是基于现有图像的程序过渡，尚未替换成专门绘制的死亡序列。
