# 兵线分散交战修正

用户截图显示中央主兵线和左下掉队单位分为两处交战。

排查发现 `updateCombat` 在攻击冷却期间，即使小兵已经在射程内，也会继续追求 `minionAttackSpot`。该站位以对方当前位置为中心计算；双方互相移动时，会形成横向追逐，将战团拉离兵线。原先波次推进仅检查中轴附近敌人，战团偏出这条区域后，推进目标会离实际交战点越来越远。

修正：攻击站位仅用于射程外接近目标；进入射程后保留当前有效攻击位置，完成普攻和后摇，直到目标离开射程或死亡才移动。无目标行军速度仍为 44，接敌移动仍为 28。

普通对局入口 `http://127.0.0.1:5173/?map=howling`，保留正常敌方 AI 与出兵，固定中央镜头观察。首波接战后保持一个局部战团，没有再像截图一样追逐到两侧。截图 `first-wave.png` 记录首波，`reinforcements.png` 记录增援汇合后的画面。短暂分组或英雄拉兵仍可能发生，本次修正针对持续追逐造成的异常分裂。

新增回归检查：射程内冷却期间不绕目标移动；正常多波模拟延长到 240 秒，每秒检查交战小兵离中轴小于 90，离自身兵线目标小于 180，覆盖此前横移和推进目标脱节问题。完整 104 文件、590 测试通过；TypeScript 与 Vite 构建通过。
