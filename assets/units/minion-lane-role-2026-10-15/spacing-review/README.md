# 小兵交战疏密优化

2026-10-15。针对普通对局中小兵聚成一团的问题，调整交战分配与间距。

- 同阵营小兵最低中心间距由 18 增至 26。敌对近战接触距离保持 18，避免推开到射程之外。
- 新选敌时，对已被同类友军锁定的敌人增加拥挤代价，引导新攻击者分散选择附近敌人。已有效锁定的目标保持稳定，英雄仇恨优先规则保留。
- 接近同一目标的站位按所有存活同类攻击者分配，跨波次也不重复使用同一个站位。近战前三个、远程前五个使用攻击弧，其余在外层等候，空位出现后补入。
- 队形小兵不再追逐偏离自身纵向列两列以上的敌方小兵；英雄的局部反击范围保留。该约束防止展开后的战团继续向两侧拖散。
- 射程内仍停稳攻击，不在普攻间隔内反复追逐站位。行军 44、接敌 28 的速度保留。

验证：4 分钟正常波次模拟检查双方近远程攻击、间距及交战区域；多单位新选敌、目标锁定稳定、跨波次站位、近战外层等候/补位、连续 E 进场及借兵撤退均有自动检查。104 个测试文件、593 项测试通过；TypeScript 和 Vite 构建通过。
