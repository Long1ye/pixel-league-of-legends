# 概念设计

## 一句话概念

一款浏览器即开即玩的原创像素风单机 1v1 中路对线 Demo：玩家通过补刀、走位和三个技能制造短暂换血窗口，逐步把兵线推到敌方核心。

## 设计锚点

- 核心幻想：在一条狭窄而危险的中路上，靠判断而不是堆系统赢下每一次补刀与换血。
- 目标体验：清晰、紧凑、可重复的“看兵线—找技能窗口—换血—回到补刀”的对线节奏。
- 玩家动机：证明自己能读懂兵线和敌方意图，并把一次小优势转化为推塔机会。
- 核心循环：移动补刀 → 观察技能与兵线 → 短暂交锋 → 处理残血小兵 → 压线或后撤 → 推塔并重开。
- 跑偏风险：变成没有兵线意义的技能打靶，或因为装备、等级、地图内容过多而失去展示重点。
- 非目标：不是完整 MOBA、联网竞技游戏、英雄池、装备构筑或长期成长产品。

## 设计锚点

《英雄联盟》只作为“中路对线的操作密度与节奏”参考，不复刻角色、技能、命名、地图、美术或具体数值。另一个参考方向是极简动作游戏对“命中、受击、危险区域”的高对比反馈：本项目借鉴反馈原则，不借用内容。

## 风格与世界观

原创世界观暂定为“潮汐遗迹中的双阵营试炼”。地图是一条被能量潮痕切开的遗迹长廊，双方守护各自的棱晶核心。角色、技能、阵营与地名均使用原创命名；世界观只服务于识别和氛围，不扩展剧情。

视觉采用有限色板的 2D 像素风：深色背景、友方青绿色、敌方橙红色、技能危险区高亮黄/红。所有视觉信息必须优先表达队伍归属、攻击范围、技能预警和受击结果。

## 目标玩家与情境

面向想快速体验核心玩法的独立游戏玩家、开发者评审者和浏览器链接接收者。单局目标为 5～8 分钟；首次进入无需安装和登录，失败后可在 2 秒内重开。

## 核心张力

补刀需要靠近兵线并暴露在敌方技能威胁中；推线能压迫敌方，却也会让己方英雄走入更深位置。玩家始终在“现在补这个刀”“现在换血”“保留技能防反打”“继续压塔还是后撤”之间做决定。

## 关键约束

- 单机、1 名玩家对 1 名 AI、单条中路、原创内容。
- 2～4 周内完成可展示版本，浏览器为第一交付目标。
- 只做一名玩家英雄、一名 AI 英雄、三种主动技能、一个中路场景。
- 不做联网、匹配、商城、符文、完整装备、野区、其他路线、复杂等级成长和完整英雄池。
