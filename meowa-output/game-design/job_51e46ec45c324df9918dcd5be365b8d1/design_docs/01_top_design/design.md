# 顶层设计

## 设计目标

在一局 5～8 分钟内，让玩家至少经历三次完整的“补刀压力—技能换血—兵线推进”循环，并能理解自己为什么赢或输。优先保证输入响应、攻击判定、兵线读数和技能预警清楚，而不是内容数量。

## 核心推动力

玩家的直接推动力是补刀与换血带来的线权：补刀提高本波推进效率，成功换血迫使 AI 后撤，兵线进入塔下后产生推塔窗口。Demo 不设置可购买经济；金币只作为补刀统计与反馈，不进入成长系统。

## 大循环

进入对局 → 争夺第一波补刀 → 利用技能制造血量优势 → 伴随兵线推进压迫敌方 → 趁敌方回撤攻击防御塔 → 摧毁敌方核心获胜 → 结算并立即重开。

## 小循环

观察小兵血量与敌方位置 → 走到合适攻击距离 → 普攻完成最后一击或施放技能 → 读取命中、受击和冷却反馈 → 选择继续补刀、后撤或追击。

## 最小体验单位

一次“可读的补刀决策”：一个敌方小兵进入斩杀血量，敌方英雄同时拥有可威胁玩家的技能；玩家移动、普攻或施放技能，得到明确的命中/漏刀/受击反馈，并改变兵线状态。

## 核心活动流程

1. 玩家以固定英雄和满血进入中路，AI 同时出场。
2. 每 20 秒生成一波小兵，双方各 3 个近战兵和 1 个远程兵，沿两条固定路点线前进。
3. 小兵接触后互相攻击；英雄可普攻小兵、英雄和防御塔。
4. 玩家按 Q/W/E 施放三个低复杂度技能：直线投射物、短距位移/减伤、地面范围伤害。技能必须有明确预警和冷却。
5. 任一英雄死亡后短暂回到己方核心附近；不设置击杀成长，击杀只造成短暂的线权窗口。
6. 兵线进入防御塔攻击范围后，塔优先攻击小兵；无小兵时可攻击英雄。
7. 摧毁敌方核心或玩家选择重开结束本局。

## 关键决策与张力

- 为了补刀靠近兵线，还是保持距离等待敌方失误。
- 把控制/位移技能用于补刀和换血，还是留作逃生。
- 技能命中后继续压线，还是利用敌方后撤安全清兵。
- 追击残血英雄，还是优先把兵线送进塔。

## 节奏结构

前 60 秒用于建立补刀和技能认知；中段由两三波兵线形成换血与回撤；后段在一次明显的兵线优势后进入塔前攻防。避免强制倒计时和复杂事件，确保玩家能复盘因果。

## 输入、输出与反馈

鼠标左键点地移动，右键或左键点目标进行普攻，Q/W/E 施法，空格锁定/取消锁定敌方英雄，R 仅作重开快捷键。HUD 显示双方生命、技能冷却、补刀数、核心耐久和胜负状态；命中采用闪白、数字、短粒子和音效占位，危险技能采用地面轮廓与颜色预警。

## 范围与非目标

MVP 只含一张固定中路、一对固定英雄、三种技能、四类可交互战斗单位（玩家、AI、小兵、防御塔/核心）。不做联网、匹配、商城、装备、符文、等级技能成长、野区、上下路、超级兵、复杂控制链、战争迷雾、回放、观战、存档、账号和手柄适配。

## 开放问题

首版可将技能效果限制为伤害、短距位移和短暂减速/减伤；若时间不足，优先保留直线技能与范围技能，位移技能降级为固定方向短冲刺。
